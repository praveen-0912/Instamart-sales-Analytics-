# Instamart Sales Analytics
This dashboard provides a complete Instamart sales performance overview with clear KPIs and interactive insights. 
## Objective
Monitor overall sales performance
→ Track total sales revenue and quantity sold.

Analyze sales by product
→ Identify top-performing and low-performing products.

Understand category performance
→ Compare sales across categories like Beverages, Dairy, Snacks, etc.

Evaluate geographic sales distribution
→ See which cities generate the most revenue.

Track monthly pricing trends
→ Analyze how unit prices change over time.

Enable interactive filtering
→ Allow users to filter by category, product, and city for deeper insights.
